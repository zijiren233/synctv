<Aside type="tip">
Use Docker Compose for a single host or first self-hosted installation. Use Helm when you already operate Kubernetes and need multiple replicas.
</Aside>

## Production Requirements

Both production paths require:

- Persistent PostgreSQL data and tested backups.
- Durable JWT, OPAQUE, and credential-encryption secrets.
- HTTPS on public entry points.
- Shared PostgreSQL, Redis, and cluster secrets for multiple replicas.
- A backup and migration check before upgrades.

After installation, complete the [Production Checklist](../production-checklist/). Existing installations should follow [Upgrades and Migrations](../../operations/upgrades/).
