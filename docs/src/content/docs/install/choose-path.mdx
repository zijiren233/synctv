<Aside type="tip">
单机或首次自托管直接使用 Docker Compose。已有 Kubernetes 运维能力并需要多副本时使用 Helm。
</Aside>

## 生产要求

两种生产部署方式都需要：

- 持久化并备份 PostgreSQL。
- 长期保存 JWT、OPAQUE 和凭据加密 secret。
- 公网入口启用 HTTPS。
- 多副本共享 PostgreSQL、Redis 和集群 secret。
- 升级前备份并验证数据库 migration。

安装完成后执行 [生产部署清单](../production-checklist/)，已有实例按 [升级与迁移](../../operations/upgrades/) 操作。
